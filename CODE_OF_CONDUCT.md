# Code of Conduct

## 1. Scope

This Code of Conduct applies to every interaction with the **Syncfusion Blazor Toolkit Templates** repository — Issues, Pull Requests, Discussions, commits, releases, and any other public space where you represent the project. The templates scaffold applications that depend on the Syncfusion Blazor Toolkit runtime component, so this Code is aligned with Syncfusion's parent [Code of Conduct and Corporate Ethics Policy](https://github.com/syncfusion/blazor-toolkit/blob/main/.github/CODE_OF_CONDUCT.md).

Where this document and the parent conflict, the parent takes precedence.

## 2. Standards

Contributors **shall**:
- Treat every other contributor, maintainer, user, and Syncfusion employee with courtesy and respect.
- Assume good faith. Ask for clarification before interpreting a statement as hostile.
- Keep issue and PR threads focused on the change at hand.
- Credit prior work. Link prior proposals. Attribute copied code.
- Respect maintainer time — run the [CLI Flag Test Matrix](CONTRIBUTING.md#cli-flag-test-matrix) before requesting review.

## 3. Prohibited Conduct

The following are **never acceptable**:

- **Harassment** in any form — verbal, written, or visual.
- **Discriminatory language or imagery** based on any protected characteristic.
- **Trolling, personal attacks, or sustained disruption** of issue or PR threads.
- **License circumvention** — for example, scaffolding an app from these templates and shipping it without a valid Syncfusion license.
- **Deceptive bug reports** — AI-generated or copy-pasted reports that do not describe a real template defect.

## 4. Maintainer Responsibilities

Maintainers will clarify and enforce these standards fairly. They may remove, edit, or reject contributions that violate this Code, and will communicate reasons for moderation decisions when appropriate.

## 5. Reporting

Please include:

1. What happened, and where (issue link, PR link, commit SHA).
2. Who was involved.
3. Your preferred contact channel for follow-up.

All violations must be reported to: **legal@syncfusion.com**

## 6. Enforcement

| Level | Trigger | Consequence |
| --- | --- | --- |
| **1. Correction** | Minor or first-time violation. | Private warning, with an explanation of why the behavior was inappropriate. |
| **2. Warning** | Sustained or repeated minor violation. | No interaction with the involved parties for a specified period. |
| **3. Temporary Ban** | Serious single violation, or persistent pattern after a Warning. | No public interaction with the project for a specified period. |
| **4. Permanent Ban** | Pattern of serious violations, harassment, or aggression toward a class of individuals. | Permanent removal from all project spaces. |

The level chosen is proportional to the violation. Repeated **License circumvention** (§3) is treated as at least a Level 3 violation, since it is a commercial risk to Syncfusion and to the template users who rely on a valid license.
